📖 Documentation

Everything you need to get accurate transcripts, searchable knowledge, diarized speakers, and useful AI answers out of Tscript AI.

Transcribing a file

  1. Upload. Drag a file into the Transcription tab, or click it to browse. You can upload a .zip (it'll find the audio/video inside automatically), a raw audio file, or a video file.
  2. Wait for processing. Your file is split into chunks behind the scenes so even long recordings transcribe reliably — this can take a few minutes for longer files.
  3. Review the table. Each row is an utterance with a timestamp, speaker role, callsign, and the transcribed text. Click ▶ to play back that exact segment.
  4. Validate. Click "✓ Validate" to flag common issues — overlapping timestamps, stray whitespace, malformed callsigns, phonetic alphabet typos, and filler words.
  5. Switch views. Use the Table / JSON / Plain Text / Paragraph controls above the results to move from structured editing to clean reading mode.
  6. Export. "⬇ Download JSON" saves the full structured transcript to your device.

Using AI Chat

  • Ask aviation, ATC, or general knowledge questions directly. Responses support Markdown, code blocks, and links.
  • Attach a file with the 📎 button, or drag and drop it anywhere in the chat window. Audio, video, PDFs, DOCX, text/code files, ZIPs, and OCR-friendly images are supported.
  • Use the 🎤 button to speak your question instead of typing (where your browser supports it).
  • Hover an AI response to Copy, Regenerate, Like/Dislike, or Share it. Hover your own message to Edit and resend it.
  • Press the send button while a reply is generating to Stop it early.

Supported formats

Audio: .wav, .mp3, .m4a, .flac, .ogg, .aac, .wma, .opus
Video: .mp4, .mov, .mkv, .avi, .webm, .flv, .wmv, .m4v — the audio track is extracted automatically.

Editing captions

  • Use the row actions column to insert a caption before/after, move it up/down, merge it with the next one, split it in two (place your cursor where you want the split), or delete it — numbering updates automatically.
  • Timestamps are editable directly in the Time column.
  • Undo / Redo in the toolbar step back and forward through your edits.
  • Use the search box + "Replace with…" + "Replace All" to fix a word or phrase across every caption at once.

Speaker labels

Each row's Role/Speaker dropdown includes Pilot, Controller, Unknown, and any custom speakers you've created. Choose "+ New custom speaker…" to add one, or click "🏷 Speakers" in the toolbar to rename or remove saved speakers. Select multiple rows with the checkboxes to apply a label — or delete — in bulk.

Exporting

The Download menu covers JSON, TXT, DOCX, PDF, SRT, VTT, CSV, and XML for transcripts, with an option to export only the segments you've checked. In AI Chat, the download icon in the top bar exports the conversation as TXT, Markdown, HTML, DOCX, or PDF.

Voice dictation

Click the 🎤 button in Chat to record a short clip for transcription into the message box (where your browser supports it). The transcription is dropped into the chat input so you can review and send it like any other message.

Annotation Expert mode

Switch to the Annotation Expert mode chip in AI Chat to check hand-action labels against the Segmentation & Labeling SOP. Paste a description and the AI will flag every rule violation (direct-command form, self-contained labels, hand specification, banned verbs, conditional words, segmentation timing), provide fixes, and rewrite it into a compliant label — all within the chat.

Code Canvas

When the AI's reply includes code, an "Open in Canvas" icon appears on the code block. Canvas opens alongside the chat with a live HTML/CSS/JS preview, editable code, tabs for multiple files, and buttons to copy, download, export a ZIP, or save the project — while you keep chatting.
